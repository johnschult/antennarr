# Security policy

If you find a security problem in Yagi, please report it privately with **Report a vulnerability** on the
[Security tab](https://github.com/johnschult/yagi/security) of this repository, not in a public issue.
Include what you found, how to reproduce it, and the version (shown at the bottom of the web page, or `yagi -version`).

How Yagi protects things, and what it doesn't, is described in [the Security page](https://yagi.johnschult.com/security/).
Only the latest release is supported.
