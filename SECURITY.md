# Security policy

If you find a security problem in Antennarr, please report it privately with **Report a vulnerability** on the
[Security tab](https://github.com/johnschult/antennarr/security) of this repository, not in a public issue.
Include what you found, how to reproduce it, and the version (shown at the bottom of the web page, or `antennarr -version`).

How Antennarr protects things, and what it doesn't, is described in [docs/security.md](docs/security.md).
Only the latest release is supported.
