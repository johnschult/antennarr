# Yagi documentation

Yagi shares an HDHomeRun tuner with Plex, Jellyfin or Emby servers on other networks, and keeps track of who is using it. Its web page also does what you would normally open the tuner's own web page for (channels, scanning, device details, restarting, firmware), with a good deal more on top.
If you haven't read the [project README](../README.md), start there for what it is and the quick start.

| Page | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are installing Yagi, or opening it for the first time |
| [A tour of the web page](web-ui.md) | You want to see what each page shows, with pictures |
| [Networking](networking.md) | You are deciding how a viewer's server will reach yours: Tailscale, a VPN, the same network, or (not recommended) the internet |
| [Media servers](media-servers.md) | You are adding the tuner in Plex, Jellyfin or Emby |
| [Configuration](configuration.md) | You want every setting, flag and file explained, and how the limits work |
| [Security](security.md) | You want to know who can do what, and what Yagi sends over the internet |
| [Troubleshooting](troubleshooting.md) | Something doesn't work: a page that won't load, a tuner that is offline, a viewer that is refused |
| [API](api.md) | You want to script against Yagi, or look at what the web page talks to |
| [Releasing](RELEASING.md) | You are making a release (maintainers) |
| [Design notes](DESIGN.md) | You are curious how it was built, or want to change it |
| [Contributing](../CONTRIBUTING.md) | You want to send a change |

These pages are for the version the app shows at the bottom of its web page. The app's **Help** link opens the pages
for that exact version, so what you read matches what you are running.

Something missing or wrong? [Open an issue](https://github.com/johnschult/yagi/issues), or send a pull request.
